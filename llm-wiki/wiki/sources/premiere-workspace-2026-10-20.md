# Adobe Premiere workspace research through Aside

A delegated Aside browser agent reported inspecting 12 public Adobe Help pages and supplied 14 references. The immutable [synthesis capture](../../raw/sources/premiere-workspace-2026-10-20.md) is explicitly not a complete browsing transcript. The reference count does not mean that every linked page was independently opened by the parent agent.

## Observed public guidance

Adobe documents [task-oriented workspaces](https://helpx.adobe.com/premiere/desktop/get-started/tour-the-workspace/what-are-workspaces.html), [docking and grouping panels](https://helpx.adobe.com/premiere/desktop/get-started/tour-the-workspace/dock-group-undock-panels.html), distinct [Source and Program Monitors](https://helpx.adobe.com/premiere/desktop/get-started/source-and-program-monitor-adjustments/about-source-monitor-and-program-monitor.html), [timeline navigation](https://helpx.adobe.com/premiere/desktop/edit-projects/change-clip-sequence/navigation-controls-in-the-timeline.html), a contextual [Properties panel](https://helpx.adobe.com/premiere/desktop/add-text-images/stylize-text/about-properties-panel.html), and deliberate [export](https://helpx.adobe.com/premiere/desktop/render-and-export/export-files/export-video.html) and [review](https://helpx.adobe.com/premiere/desktop/collaborate-with-others/share-for-review-using-frame-io/share-for-review-with-frame-io.html) steps. Its [accessibility guidance](https://helpx.adobe.com/premiere/desktop/get-started/set-up-accessibility-features/screen-reader-screen-magnifier-and-operating-system-accessibility-support.html) also describes limitations; Adobe behavior is not automatically the accessibility target for this project.

## Inference and implementation boundary

The adaptation combines the user's sage/white FRAME blueprint with task navigation, real channel hierarchy, a scene bin, a monitor-over-timeline arrangement and the existing inspector. It does not clone all Premiere functionality. Research recommendations about skip routes, conditional stages, independent tracks or Frame.io are not claims that those features exist in FrameForge.

The agent's manual Jev API review returned `proposal_only` with an unvalidated `jev-1.13.0` backend and insufficient evidence confidence. This was a research proposal review, not final-diff approval, deployment evidence or host authorization. The parent `jeo` profile was disabled and was not replaced with another profile. The returned advisory result and receipt are retained in the [sanitized research artifact](../../../artifacts/premiere-workspace-research.json).

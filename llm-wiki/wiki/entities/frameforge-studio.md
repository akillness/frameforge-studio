# FrameForge Studio

The repository contains a Node HTTP service, SQLite persistence, a browser editor, local FFmpeg rendering and an optional host agent bridge. These components support the requested [[wiki/concepts/production-history]] and [[wiki/concepts/knowledge-layers]].

Provider availability, Docker health, account binding and network access are environment-specific. Consult current verification receipts instead of treating this entity page as deployment proof. Origin: [[wiki/sources/product-brief]].

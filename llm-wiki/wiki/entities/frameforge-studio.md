# FrameForge Studio

The repository contains a Node HTTP service, SQLite persistence, a browser editor, local FFmpeg rendering and an authenticated host agent/speech bridge. These components support the requested [[wiki/concepts/production-history]] and [[wiki/concepts/knowledge-layers]].

Provider availability, Docker health, account binding and network access are environment-specific. Consult current verification receipts instead of treating this entity page as deployment proof. Origin: [[wiki/sources/product-brief]].

Current deployment and preserved migration evidence: [[wiki/reports/runtime-verification-2026-10-18]]. Linux containers use installed Windows voices through the bridge, with explicit capability checks.

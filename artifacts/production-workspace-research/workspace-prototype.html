공개 전, 하나의 최종 승인

최종 승인은 장면별 생성 동의와 별개입니다. 아래 항목이 정확한 하나의 출력에 묶여야 합니다. 이 프로토타입에서는 어느 항목도 운영 검증되지 않았습니다.

대상 채널 / 소유자
확인해봄은 의도한 채널명일 뿐입니다. OAuth 계정·채널 ID·소유 권한 미검증.
정확한 출력
45초 Shorts 브리프만 존재. 프로젝트/에피소드 버전, 렌더 작업, 파일 및 SHA-256 없음.
소스 / 이용 권리
영상·이미지 미첨부. 실제 소스 URL·라이선스·출처 표기·취득 시각·파일 해시·사용 구간 미검증.
제목 / 설명 / 메타데이터
실제 게시 제목·설명·출처 표기 및 관련 메타데이터 미확정·미검증.
시청 대상
아동용 여부 미결정·미검증. selfDeclaredMadeForKids에 바인딩 필요.
AI 사용 공개
사람의 정책 검토 및 공개 여부 결정 없음. containsSyntheticMedia에 바인딩 필요. 단순 제작 보조만으로 자동 결정하지 않음.
최종 공개 범위
사용자 확인 방향은 최종 승인 직후 public. 현재 원격 영상 ID·처리 상태·공개 상태 미검증.
구현되어야 할 공식 OAuth/API 경로
  1. 채널에 바인딩된 OAuth 및 insert/read/update 권한 확인
  2. 정확한 승인 후보를 비공개 업로드
  3. 동일 영상의 채널·메타데이터·시청 대상·AI 공개·처리 완료 읽기 확인
  4. 승인 입력을 재확인한 뒤 동일 영상 public 변경
  5. 영상 ID·채널·공개 상태·시청 대상·AI 공개 재조회

모호한 결과는 같은 영상 ID로 확인하며 새 업로드로 재시도하지 않습니다. Studio 자동화는 연결하지 않습니다.

공개 게시 불가. OAuth/API 구현과 정확한 후보 증거가 연결되지 않았습니다. 이 창은 항목을 보여줄 뿐, 승인 기록이나 게시 성공을 만들지 않습니다.

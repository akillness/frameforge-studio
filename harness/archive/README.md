# Prior harness releases

This directory holds immutable snapshots of previously active project harness versions. The linear 1.0.0 contract was promoted before the node-workflow 1.1.0 contract; the actual promotion creates its archive. No release predating 1.0.0 is fabricated. `scripts/version-harness.mjs` adds a validated archive only when an actual active version is replaced.

Historical external directories `shorts-harness`, `sports-shorts-harness` and `sports-shorts-harness-v2` are reference sources, not imported project releases. Their private media, account bindings and operational receipts stay outside this repository.
